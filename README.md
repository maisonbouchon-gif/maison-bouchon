# Maison Bouchon

Application web installable (iPhone et ordinateur) pour suivre le chantier de la maison : travaux, devis, dépenses et budget.

- Données et pièces jointes : Supabase (accès limité au compte de la famille, voir `supabase/schema.sql`).
- Lecture automatique des devis : fonction Supabase `supabase/functions/lire-devis`.
- Hébergement : GitHub Pages (branche `main`, dossier racine).
